DS2 Vehicle Boarding Fast-Forward

English

1. Close the game.
2. Copy the contents of this folder into the game root.
   The game root is the folder that contains the game executable.
3. Expected layout after copying:
  <GameRoot>\version.dll
  <GameRoot>\scripts\ds2_vehicle_boarding_trace.asi

version.dll is the ASI loader (Ultimate ASI Loader).
ds2_vehicle_boarding_trace.asi is the mod plugin.

中文

1. 关闭游戏。
2. 将本文件夹内的内容复制到游戏根目录。
   游戏根目录是包含游戏 exe 的目录。
3. 复制后目录应为：
  <游戏根目录>\version.dll
  <游戏根目录>\scripts\ds2_vehicle_boarding_trace.asi

version.dll 是 ASI 加载器（Ultimate ASI Loader）。
ds2_vehicle_boarding_trace.asi 是 Mod 插件。
